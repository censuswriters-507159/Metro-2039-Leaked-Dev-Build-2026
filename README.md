## 🕹️ About

METRO 2039 is a single-player first-person shooter set in the ruined Moscow Metro after nuclear war. Play as the Stranger through a bleak story of survival, psychological horror, exploration, combat, stealth, mutants, and collapsing station communities. This unofficial Windows build is an unfinished leak that surfaced ahead of the planned release and is not affiliated with 4A Games or Deep Silver.

For players who want a tense, story-focused post-apocalyptic shooter built around atmosphere, survival, stealth, and dread.

> ⚠️ **This is an unofficial leaked pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.Archive is password protected (`2026`) to compatibility automated DMCA bots and hosting service scanners that would otherwise delete the files within hours.
